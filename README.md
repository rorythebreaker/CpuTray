# CpuTray

Маленькая программа для трея Windows для ноутбуков на AMD Ryzen (проверялась на Ryzen 5 7535HS).

- **ЛКМ** по иконке — температура CPU (Tctl), загрузка CPU, занятая RAM, текущий режим и лимит TDP.
- **ПКМ** — меню режимов:
  - **Тихий** — отключает Turbo Boost (через схему питания Windows) и снижает лимиты мощности
    через RyzenAdj: STAPM 15 Вт, Fast 20 Вт, Slow 15 Вт, порог температуры 80 °C.
  - **Обычный** — возвращает исходные значения, которые были сохранены перед включением тихого режима.
- На иконке показана температура. Цвет иконки: синий — обычный режим, зелёный — тихий, красный — 85 °C и выше.
- При выходе из программы всё возвращается к исходным значениям.

## Запуск

Скачайте `CpuTray.exe` из [Releases](../../releases) и запустите. Программа попросит права администратора:
без них невозможно читать температуру и менять TDP.

При запуске программа распаковывает рядом с exe библиотеки RyzenAdj (`libryzenadj.dll`, `WinRing0x64.*`, `inpoutx64.dll`).
Если Windows Defender заблокирует `WinRing0x64.sys`, добавьте папку с программой в исключения.
Без драйвера температура будет «н/д», а тихий режим будет работать только за счёт отключения Turbo Boost.

## Сборка

Нужен только штатный компилятор .NET Framework 4 (он есть в Windows):

```powershell
.\build.ps1   # → dist\CpuTray.exe
```

## Сторонние компоненты

Папка `native/` содержит файлы из [RyzenAdj](https://github.com/FlyGoat/RyzenAdj) v0.19.0 (LGPL-3.0),
включая WinRing0 (BSD) и InpOut.
